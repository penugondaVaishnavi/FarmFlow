
# 🌱 FarmFlow

### *From the farm to your plate, every step visible.*

FarmFlow is a web app that tracks farm produce through the whole supply chain, so everyone from the farmer to the consumer can see where food comes from and how it got to them.

## Why FarmFlow?

Food often passes through many hands before it reaches us, and the people involved rarely get the full picture. FarmFlow aims to fix that:

- **Farmers** get fair credit and visible earnings for what they grow.
- **Distributors and retailers** get a clear record of every batch they handle.
- **Consumers** can scan or search a product and trace its journey back to the farm.
- **The planet** benefits from carbon footprint tracking along the way.

## Our Motto

> Transparent food. Fairer farming. A traceable journey for every batch.

## How It Works

1. **Farmer** creates a batch of produce.
2. **Collection center** receives and verifies the batch.
3. **Distributor** ships it onward.
4. **Retailer** stocks it and manages inventory.
5. **Consumer** traces the full journey using the public trace page.

## Features

- Role-based dashboards for farmers, collection centers, distributors, and retailers
- Batch creation, tracking, and earnings
- Public consumer trace page
- Carbon footprint calculator
- PDF report generation
- Global search, profile, and transaction history
- Offline support

## Tech Stack

- React
- TypeScript
- Vite

## Getting Started

Requires [Node.js](https://nodejs.org).

```bash
cd front
npm install
copy .env.example .env
npm run dev
```

Open the local URL shown in the terminal.
